# Legacy SCI concept

The earlier manuscript explored **Systolic Completion Instability (SCI)** from routine apical 4-chamber cavity motion. SCI summarized four concepts: residual post-systolic narrowing, delayed completion burden, completion heterogeneity, and delayed segment fraction.

After direct clarification from the EchoRisk organizers, the challenge-distributed dataset was determined not to be available for this independent journal use. For that reason:

- EchoRisk/CARDIOCARE patient-level data are **not included** here;
- the earlier numerical SCI results are **not used as evidence** in the MTI manuscript; and
- the current public-data study should be evaluated on its own results.

The intellectual continuity is mechanistic: both studies ask whether **temporal mechanical vulnerability on echocardiography can be detected before conventional systolic dysfunction**. SCI used 2D cavity motion; MTI uses Tissue Doppler myocardial velocity.
