# GitHub Pages setup

The website is already integrated under `docs/` and the deployment workflow is at `.github/workflows/pages.yml`.

1. Push this repository release to the `main` branch.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **GitHub Actions**.
5. Open **Actions** and confirm that **Deploy research website to GitHub Pages** completes successfully.
6. The expected site URL is:

   `https://rdharini2001.github.io/MTI_CardioOncology/`

The site is static and requires no Vercel configuration, npm build, or external JavaScript framework.
