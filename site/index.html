THE QUESTION

Can a single pretreatment TDI cycle reveal myocardial vulnerability before LVEF falls?

MTI compresses the systolic-to-relaxation transition into four interpretable timing and morphology features. Higher MTI reflects a slower, blunted, later, and attenuated transition into early relaxation.

ANALYSIS PIPELINE

Interpretable by construction

The score is deliberately simple: four oriented features, training-fold standardization, equal weights.

01

Normalize one cycle

Each public TDI trajectory is represented on 1,001 phases from 0 to 1.

02

Landmark motion

Identify S peak, systolic zero crossing, and the subsequent E′ nadir after Savitzky-Golay smoothing.

03

Describe transition

Measure slope deficit, curvature deficit, early-relaxation latency, and E′ attenuation.

04

Validate without leakage

Standardize and fit only in training folds across 100 repeated stratified 5-fold partitions.

MTI = ¼ ( zslope + zcurvature + zlatency + zE′ attenuation )

All components are oriented so higher values indicate greater mechanical-transition abnormality.

Primary inferential target

Time to CTRCD using Cox proportional hazards models. Effect size is HR per 1-SD higher MTI.

  • MTI alone
  • MTI + baseline LVEF
  • Age + LVEF adjustment
  • Treatment-adjusted complete-case sensitivity

Robustness

  • Preserved baseline LVEF ≥50%
  • Smoothing windows 21 to 61 samples
  • Leave-one-component-out analyses
  • Whole-waveform functional permutation testing
  • Continuous spline test for nonlinearity

CURRENT PUBLIC-DATA STUDY

Mechanical Transition Instability

Tissue Doppler echocardiography → myocardial velocity over time.

  • Transition slope deficit
  • Transition curvature deficit
  • Early-relaxation latency
  • E′ attenuation
What is preserved? Both approaches use echocardiography to ask whether abnormal temporal mechanics precede conventional systolic dysfunction. SCI emphasized spatially heterogeneous cavity completion; MTI uses a temporal TDI surrogate because it is the reproducible signal available in the fully public cohort.
